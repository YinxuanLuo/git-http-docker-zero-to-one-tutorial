# Git / 网络 HTTP / Docker · 从零到一

> 一本教程，三个主题。面向**有 JavaScript 基础、但没系统学过这三样**的程序员。
> 每个主题都从「设计哲学」讲到「面试速查」，每段代码都能在你机器上真的跑起来。

---

## 这套教程是什么

市面上的 Git / HTTP / Docker 教程，要么是零散的命令速查（看完还是不懂为什么），要么是高高在上的理论书（看完不会用）。

这套教程不一样。它有三个铁打不动的规矩：

1. **把读者当最笨的人**——每个知识点拆到不能再拆，但绝不灌水，每一句都有信息量。
2. **讲「为什么这么设计」**——Git 为什么是快照不是差异？HTTP 为什么要分层？Docker 为什么能解决"我本地好好的"？每个专题都先回答这个。
3. **报错必须真实**——带你亲手复现 `CONFLICT (content)`、`404 Not Found`、`Unable to find image`，报错不靠想象。

## 双轨路线图

每篇都有两条路线，按你的情况选一条：

| 路线 | 适合谁 | 时长 | 入口 |
|---|---|---|---|
| 🚀 速通版 | 只想先上手、要面试前突击 | 约 2 小时/篇 | `速通版-2小时上手Git.md` 等 |
| 📖 完整版 | 想真正搞懂、系统学 | 每篇 12 章 | 各篇 `docs/<篇>/00` 开始 |

**三篇没有强依赖，但推荐顺序：Git → 网络 HTTP → Docker。**
理由：Docker 的镜像仓库（Registry）本质是 HTTP 服务，Dockerfile 的写法又离不开命令行——先懂 HTTP 和命令行，Docker 才看得懂。

## 第一篇 · Git（版本控制）

> 12 章，从「Git 到底在存什么」讲到「rebase、reflog、钩子」。

- **00 设计哲学**：Git 不是保存你的文件，是保存一个**内容寻址的对象数据库**
- **01 心智模型**：工作区 / 暂存区 / 版本库，三棵树
- **02~07 核心**：commit 与日志 → 分支与合并 → 冲突 → 撤销与回退（reset/revert/reflog）→ 远程协作 → rebase 与历史整理
- **08 工程化**：.gitignore / 钩子 / 子模块 / 大文件
- **09 实战**：从零做一个规范的协作流程
- **10 测试题** / **11 面试速查**

---

## 第二篇 · 网络与 HTTP（网络协议）

> 12 章，从「敲下回车发生了什么」讲到「HTTP/2、TLS、抓包」。

- **00 设计哲学**：分层——每一层只跟邻居说话
- **01 心智模型**：TCP/IP 四层模型，数据是怎么"包起来又拆开"的
- **02~07 核心**：TCP 三次握手与可靠传输 → IP 与 DNS → HTTP 报文与方法/状态码 → HTTPS 与 TLS → 缓存与 Cookie → HTTP/1.1 到 HTTP/2、HTTP/3
- **08 工程化**：REST 设计、抓包调试（Node 里起服务亲眼看报文）
- **09 实战**：从零写一个能处理请求的 HTTP 服务器
- **10 测试题** / **11 面试速查**

---

## 第三篇 · Docker（容器化）

> 12 章，从「镜像是什么」讲到「Dockerfile、compose、网络与卷」。

- **00 设计哲学**：把「代码 + 运行环境」打包成**不可变的镜像**
- **01 心智模型**：镜像 / 容器 / 仓库，容器 vs 虚拟机
- **02~07 核心**：镜像与分层 → 容器生命周期 → Dockerfile → 网络 → 卷与持久化 → compose
- **08 工程化**：多阶段构建 / 镜像瘦身 / 最佳实践
- **09 实战**：把一个 Node 应用容器化并编排
- **10 测试题** / **11 面试速查**

## 环境准备

- **Node.js 22 LTS**（示例全部用 `.mjs`，`node xxx.mjs` 直接跑，零第三方依赖）
- **Git**（Git 篇的示例需要）
- **Docker**（Docker 篇的示例**不是必须**——没有 Docker 也能看懂全部概念；装了 Docker 就能亲手跑）

三篇的 `.mjs` 示例都只在 Node 内置模块上跑，**不需要 `npm install`**。
唯一需要装依赖的是 `tools/`（构建阅读版/练习站用，`cd tools && npm install`），普通读者不需要碰它。

---

## 三条铁律（全系列通用）

1. **先给结论，再讲原因。** 每个知识点先告诉你"是什么、为什么"，再展开。
2. **每节结尾有「一句话记住它」。** 学完一章，脑子里留一句能复述的话，而不是一团浆糊。
3. **坑必须先踩再懂。** 每个坑都给你一个能复现的最小例子，你亲手踩过，才记得住。
